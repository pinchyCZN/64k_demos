UKKO - "StickMan's World"

A 64k DOS demo by Coma, dated 11 August 1995. A rotoscoped stick figure dances to a Scream Tracker module in 320x200 mode 13h, drawn one pixel at a time by a hand-written assembly line router. 705 keyframes of twelve joints, eight tween steps between each.

This is not an emulator. The original 52,836-byte UKKO.EXE is embedded in this page, and the PKLITE container it ships in is unpacked in memory every time the page loads - the demo's own data is then read straight out of that image. The code that draws it is a reconstruction in ANSI C, written from the disassembly.

The bicycle game at the end is not in the original. The demo stops at keyframe 694; that part is ours.

KEYS

spacepause and resume, music and all
.single step one frame while paused
ffast forward, while held
[ ]step back and forward through the scenes
mmute
+ -volume, five steps
mousedrag the dancer about - let go and he springs back

KEYS - THE BICYCLE GAME

cjump - tap for a small one, hold for height
zwheelie, while held
xthrottle - hold it and the speed keeps building

A keyboard is needed for all of the above, so a phone will play the demo but not drive it.

The reconstruction is src/: one C function per function in the disassembly, carrying the name the database uses. src/pklite.c is the unpacker, src/ukko/ the demo itself, and src/main_sdl.c the only file that loops - the same body serves this page and a native SDL2 build. What was established about the original, and how, is written up under docs/ukko/.
